# Guía de SQL Server

Este documento proporciona una guía completa sobre SQL Server, incluyendo su instalación, configuración y conceptos básicos.

## ¿Qué es SQL? 
📚  
SQL (Structured Query Language) es un lenguaje de programación estándar utilizado para gestionar bases de datos. Se usa para realizar tareas como la creación, lectura, actualización y eliminación de datos en bases de datos.

## Características
✨  
- **Lenguaje Declarativo**: Se centra en el "qué" se desea obtener y no en el "cómo" hacerlo.
- **Lenguaje Estándar**: SQL es el estándar de la industria para la gestión de bases de datos.
- **Interoperabilidad**: SQL funciona con muchas plataformas de bases de datos como MySQL, PostgreSQL, y SQL Server.

## Usos comunes de SQL
🔍  
- **Consultas de Datos**: Extracción de datos de una base de datos.
- **Administración de Bases de Datos**: Crear, modificar o eliminar tablas y relaciones.
- **Control de Acceso**: Definir permisos y roles para usuarios.

## ¿Qué es Microsoft SQL Server?
🖥️  
Microsoft SQL Server es un sistema de gestión de bases de datos relacional desarrollado por Microsoft. Proporciona un conjunto de herramientas para administrar bases de datos grandes y pequeñas, con soporte para transacciones, seguridad, y un alto rendimiento.

## Consultas SQL Server 2022
📝  
SQL Server 2022 trae nuevas funciones para mejorar el rendimiento, la seguridad y la conectividad. Las consultas permiten la interacción con las bases de datos, incluyendo operaciones como `SELECT`, `INSERT`, `UPDATE`, y `DELETE`.

## Ediciones de SQL Server
🔧  
SQL Server viene en varias ediciones que se adaptan a las necesidades de diferentes usuarios y empresas:

### SQL Server 2022 Enterprise
🏢  
Esta edición está diseñada para grandes empresas con necesidades avanzadas de alta disponibilidad, rendimiento y escalabilidad.

### SQL Server 2022 Standard
📊  
La edición estándar es ideal para pequeñas y medianas empresas. Ofrece muchas características, pero con un costo más accesible.

### SQL Server 2022 Web
🌐  
Optimizada para aplicaciones web, esta edición es más económica y se enfoca en ofrecer soporte para sitios web y aplicaciones en la nube.

### SQL Server 2022 Azure
☁️  
Esta versión está diseñada para entornos de nube, ofreciendo integración con Azure para escalar de forma flexible según las necesidades del negocio.

### SQL Server 2022 Express
💡  
Una edición gratuita y ligera, ideal para desarrolladores, pruebas y aplicaciones pequeñas.

### SQL Server 2022 Developer
💻  
SQL Server Developer es una edición completa, pero solo para fines de desarrollo y pruebas. Es gratuita y permite acceder a todas las características de SQL Server.

## Instalación de SQL Server 2022 Developer en español
⚙️  
Para instalar SQL Server 2022 Developer en español, sigue estos pasos:
1. Descarga el instalador desde el sitio oficial de Microsoft.
2. Ejecuta el instalador y selecciona las opciones correspondientes, incluyendo la instalación de Management Studio.
3. Durante la instalación, selecciona "Español" como idioma de instalación.

## Activar el usuario Administrador en Windows 10 Home Single Language o Windows 10 Home
🔒  
1. Abre el **Símbolo del sistema** como administrador.
2. Escribe el comando: `net user administrator /active: yes`.
3. Reinicia tu computadora y deberías ver la cuenta de Administrador activada.

## Activar el usuario Administrador en Windows 10 Pro
🔑  
1. Abre el **Símbolo del sistema** como administrador.
2. Escribe el comando: `net user administrator /active: yes`.
3. Reinicia la computadora y podrás acceder con la cuenta de Administrador.

## Instalación de SQL Server Developer en Windows Home Single Language
🖥️  
1. Descarga el instalador de SQL Server Developer desde el sitio oficial de Microsoft.
2. Ejecuta el instalador y sigue las instrucciones en pantalla.
3. Asegúrate de seleccionar "SQL Server Developer" y el idioma adecuado durante la instalación.

## Configuración a Español Windows 10 Pro antes de instalar SQL Server
🌍  
1. Abre **Configuración** y ve a **Hora e idioma**.
2. En **Región e idioma**, selecciona **Español** como idioma predeterminado.
3. Reinicia tu computadora antes de proceder con la instalación de SQL Server.

## Instalación de SQL Server Developer en Windows Pro
⚙️  
1. Descarga el instalador desde el sitio oficial de Microsoft.
2. Ejecuta el instalador y sigue las instrucciones para seleccionar las características de SQL Server que deseas instalar.
3. Asegúrate de seleccionar **SQL Server Developer**.

## Instalación de Management Studio en Windows Home Single Language
🔧  
1. Descarga **SQL Server Management Studio (SSMS)** desde el sitio web de Microsoft.
2. Ejecuta el instalador y sigue las instrucciones.
3. Una vez instalado, podrás administrar tu base de datos SQL Server.
